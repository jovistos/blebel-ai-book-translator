# Development-only dependencies for the book translator.
#
# Canonical dependency definitions live in pyproject.toml. This file is kept as
# a compatibility shim for:
#
#   pip install -r requirements-dev.txt
#
# which is now equivalent to an editable install with the dev extra:
#
#   pip install -e ".[dev]"
#
# The lint/type/test versions are pinned in pyproject.toml: the CI workflow and
# the golden snapshots in tests/snapshots/ are only meaningful against a known
# toolchain. The dev extra also includes chonkie, tiktoken, rapidfuzz and
# markdown-it-py, so the whole offline suite runs without the heavy convert /
# dictionary extras (their tests stub docling and the NER taggers).

-e .[dev]
