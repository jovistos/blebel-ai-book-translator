# Runtime dependencies of the book translator.
#
# Canonical dependency definitions live in pyproject.toml. This file is kept as
# a compatibility shim for the historical install command:
#
#   pip install -r requirements-book-translator.txt
#
# which is now equivalent to installing the project plus the stage 5/6 extras:
#
#   pip install -e ".[chunk]"
#
# Python 3.11+ is required: the per-stage model config (book_translator.toml) is
# read with the standard library's tomllib, so there is no YAML/TOML dependency.
#
# The core install covers stages 1, 2, 4, 6b, 7, 8 and 9, plus the Markdown path
# of stage 11. Optional stages are installed as extras:
#
#   convert     stage 0  — docling (EPUB/text-based PDF -> Markdown)
#   dictionary  stage 3  — classla / stanza / lingua-language-detector
#   chunk       stage 5  — chonkie + tiktoken, plus rapidfuzz for stage 6
#   epub        stage 11 — markdown-it-py
#
# Every optional import is lazy, so a split-only install keeps working without
# any of them. Stage 4 and stage 7 reuse the core langchain-openai client.
#
# Stage 6 (`book_translator chunk-glossary`) also needs a tagger: install the
# dictionary extra as well before tagging real chunks.

-e .[chunk]
